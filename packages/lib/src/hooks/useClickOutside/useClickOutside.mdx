<Title>useClickOutside</Title>

`useClickOutside` invokes a callback when a `mousedown` event occurs outside a referenced element.

## Usage

```tsx
import { useRef } from 'react';
import useClickOutside from './useClickOutside';

function Menu({ onDismiss }: { onDismiss: () => void }) {
  const menuRef = useRef<HTMLDivElement>(null);
  useClickOutside(menuRef, onDismiss);

  return (
    <div ref={menuRef}>
      <button type="button">Menu item</button>
    </div>
  );
}
```

## API

```ts
useClickOutside<T extends HTMLElement | null>(
  ref: React.RefObject<T>,
  callback: (event: MouseEvent) => void,
): void;
```

The callback receives the original `MouseEvent`. Events whose target is inside the referenced
element are ignored, as are events fired while the ref is empty. The hook listens on `document` and
stops propagation for document `mousedown` events.
