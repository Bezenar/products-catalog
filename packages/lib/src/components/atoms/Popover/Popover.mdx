<Title>Popover</Title>

Popover displays content relative to an anchor. Its visibility is controlled by the
`isContentVisible` prop, and `onOutsideClick` lets the owning component decide how to close it.

## Usage

```tsx
<Popover
  anchor={<button type="button">Open options</button>}
  isContentVisible={isOpen}
  onOutsideClick={() => setIsOpen(false)}
  position="bottom-left"
>
  <div>Popover content</div>
</Popover>
```

Supported position values are `bottom-left`, `bottom-right`, `bottom-center`, `top-left`,
`top-right`, `top-center`, `left-top`, `left-center`, `left-bottom`, `right-top`, `right-center`,
and `right-bottom`.

## Positioning Note

Popover coordinates are calculated from the anchor's `getBoundingClientRect()` and updated on
window scroll. Storybook renders stories inside an iframe, whose viewport can produce different
fixed-position coordinates than the consuming application. This page intentionally documents the
API without embedding a live preview; verify final placement in the application viewport.
