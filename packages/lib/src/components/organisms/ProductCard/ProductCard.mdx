<Title>ProductCard</Title>

`ProductCard` composes a product image, heading, content area, secondary text, and an optional badge. It is a visual container by default. Supplying `onClick` renders the card as a native button, so it can be activated with a mouse, Enter, or Space.

## Import

```tsx
import ProductCard from 'lib/organisms/ProductCard';
```

## Display-only card

```tsx
<ProductCard>
  <ProductCard.Badge value="New" />
  <ProductCard.Image src={imageUrl} alt="" />
  <ProductCard.Content>
    <ProductCard.Heading>Dream Router</ProductCard.Heading>
    <ProductCard.SecondaryText>UDR</ProductCard.SecondaryText>
  </ProductCard.Content>
</ProductCard>
```

## Clickable card

Use `onClick` for an action, such as opening a details view. The card becomes a button, and its accessible name is derived from its text content.

```tsx
<ProductCard onClick={() => openDevice(device.id)}>
  <ProductCard.Badge value="New" />
  <ProductCard.Image src={imageUrl} alt="" />
  <ProductCard.Content>
    <ProductCard.Heading>{device.product.name}</ProductCard.Heading>
    <ProductCard.SecondaryText>{device.shortnames.join(' ')}</ProductCard.SecondaryText>
  </ProductCard.Content>
</ProductCard>
```

Don't put another button, link, input, or other interactive control inside a clickable card. If the entire card represents navigation, prefer a link as the interactive root rather than nesting a link inside the button.
