# createServiceFn

`createServiceFn` wraps an asynchronous service function with lifecycle callbacks and optional response adaptation. It preserves the wrapped function's argument types and infers the `onSuccess` value from the adapter's return type.

## Options

  <thead>
    <tr>
      <th>Option</th>
      <th>Description</th>

  </thead>
  <tbody>
    <tr>
      <td>
        <code>adapter</code>

      <td>Optional function that transforms the resolved service result.</td>

        <code>onSuccess</code>
      </td>
      <td>

      </td>
    </tr>
    <tr>
      <td>
        <code>onError</code>

      <td>Called with a service error. The error is handled and not rethrown.</td>
    </tr>

      <td>

      </td>
      <td>Optional callback invoked before the service function.</td>
    </tr>
    <tr>
      <td>
        <code>onComplete</code>
      </td>
      <td>Optional callback invoked after success or failure.</td>
    </tr>
  </tbody>
</table>

## Adapt a response

```ts
import { createServiceFn } from 'lib';

const getProductNames = createServiceFn((category: string) => api.getProducts(category));

await getProductNames(['routers'], {
  adapter: (products) => products.map((product) => product.name),
  onSuccess: (names) => {
    // names is inferred as string[]
    console.log(names);
  },
  onError: (error) => {
    console.error(error);
  },
  onBeforeRequest: () => {
    console.log('Loading products');
  },
  onComplete: () => {
    console.log('Request finished');
  },
});
```

## Pass through the response

Omit `adapter` to receive the original resolved result in `onSuccess`:

```ts
await getProductNames(['routers'], {
  onSuccess: (products) => {
    console.log(products);
  },
  onError: (error) => {
    console.error(error);
  },
});
```

The callback order is `onBeforeRequest`, service function, `onSuccess` or `onError`, then `onComplete`.
