<Title>cn</Title>

`cn` builds a class-name string from string arguments and conditional class maps. Arguments are processed from left to right, and the final result is trimmed.

## Type signature

```ts
function cn(...args: unknown[]): string;
```

- **Arguments:** any number of values typed as `unknown`.
- **String arguments:** appended to the result in the order supplied.
- **Object arguments:** keys are appended only when their values are the boolean `true`.
- **Other values:** numbers, booleans, `null`, `undefined`, arrays, and object properties with non-boolean values are ignored.
- **Return value:** a space-separated `string`; duplicate class names are preserved.

## Import

```ts
import { cn } from 'lib/utils';
```

## Join static classes

```ts
const buttonClassName = cn('button', 'button-primary');
// "button button-primary"
```

## Add conditional classes

```ts
const isActive = true;
const isDisabled = false;

const navigationClassName = cn('navigation-item', {
  'navigation-item--active': isActive,
  'navigation-item--disabled': isDisabled,
});
// "navigation-item navigation-item--active"
```

## Combine strings and class maps

```ts
const sizeClassName = cn('card', { 'card--compact': true }, 'card--interactive');
// "card card--compact card--interactive"
```

## Ignore unsupported values

```ts
const className = cn('button', false, null, ['not-added'], { expanded: 1 });
// "button"
```
