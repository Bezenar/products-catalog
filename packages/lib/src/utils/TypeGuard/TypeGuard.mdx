<Title>TypeGuard</Title>

`TypeGuard` provides static predicates for checking common JavaScript value categories. Each predicate accepts `unknown` and narrows the value's TypeScript type when it returns `true`.

## Usage

Import the class from the library package:

```ts
import { TypeGuard } from 'lib';
```

### Check strings

```ts
function formatLabel(value: unknown): string {
  if (TypeGuard.isString(value)) {
    return value.trim().toUpperCase();
  }

  return 'UNKNOWN';
}
```

### Check booleans

```ts
function describeFlag(value: unknown): string {
  if (TypeGuard.isBoolean(value)) {
    return value ? 'Enabled' : 'Disabled';
  }

  return 'Not a boolean';
}
```

### Check arrays

```ts
function itemCount(value: unknown): number {
  if (TypeGuard.isArray(value)) {
    return value.length;
  }

  return 0;
}
```

### Check objects

```ts
function objectKeys(value: unknown): string[] {
  if (TypeGuard.isObject(value)) {
    return Object.keys(value);
  }

  return [];
}
```

`isObject` only checks the broad JavaScript object category. It does not verify an object's properties or guarantee a specific interface; validate the shape separately before relying on particular fields.
