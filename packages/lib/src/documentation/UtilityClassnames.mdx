# Spacing step

Currently are declared **4px**.

Step variable are stored at **src/lib/assets/styles/variables.scss** as **§stepValue**. If appear needs
to change step value, it should be changed there.

Step value will be applied for spacing like margin, padding, gap in flex elements. Any spacing
classname have number, as example _ma-1_, _pa-1_, _gap-1_. This number will be applied as number which
multiply step value, as example: \**\<spacing-classname\>-3*3= 3 \* 4px = 12px;

```diff
- Currently max number in spacing classname are 10.
```

# Flex

Main classname to create flex element **flex**.

```HTML
<div class="flex"></div>
```

This classname have nested classnames, let's name it as additional flex classnames. This additional classnames will work only if **flex** classname is provided.

## Additional flex classnames

### flex direction

- **dir-row** - _flex-direction: row;_
- **dir-row-rev** - _flex-direction: row-reverse;_
- **dir-col** - _flex-direction: column;_
- **dir-col-rev** - _flex-direction: column-reverse;_,

```HTML
<div class="flex dir-row">< /div>
<div class="flex dir-row-rev"></div>
<div class="flex dir-col"></div>
<div class="flex dir-col-tev"></div>
```

# Margin & Padding

Classname structure

> \<spacing\>\<direction\>-\<steps\>

** \<spacing\> ** available values

- **m** - for margins
- **p** - for paddings

** \<direction\> ** available values

- **t** - top side
- **b** - bottom side
- **l** - left side
- **r** - right side
- **x** - left and right side
- **y** - top and bottom side
- **a** - all sides

** \<steps\> ** available values in range 1 - 10.

```HTML
<div class="mr-1"></div> <!-- margin-right: 4px; -->
<div class="mx-2"></div> <!-- margin-right: 8px; margin-left: 8px; -->
<div class="pa-3"></div> <!-- padding: 12px; -->
<div class="mt-1 ml-3 mr-4"></div> <!-- margin-top: 4px; margin-left: 12px; margin-right: 16px; -->
<div class="ma-2 pa-2"></div> <!-- margin: 8px; padding: 8px -->
```
